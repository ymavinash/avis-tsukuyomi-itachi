## 01 — THE IDEA

**Tsukuyomi** is a personal creative-development project built around one of the characters who has had the strongest influence on me — **Itachi Uchiha**.

Rather than building another static character page, I wanted to create something that feels like **entering a memory**.

The experience is designed around:

- darkness
- silence
- red moonlight
- Sharingan symbolism
- Japanese typography
- crows
- ink-like shadows
- cinematic transitions
- subtle motion
- fragments of memory
- and the contrast between what Itachi showed the world and what he carried privately

The goal is not simply to display information about Itachi.

The goal is to **make the user feel the atmosphere surrounding his story.**
